# 职路AI - 大学生求职导航平台

## 项目背景

参加TRAE「AI 无限职场」SOLO 挑战赛公益赛道，帮助大学生跨越求职迷茫，让信息不对称与经验缺乏不再成为障碍。

## 核心价值主张

让大学生清楚知道：

* **下一步是什么** - 岗位真实工作内容与能力要求

* **怎么走** - 阶段性行动清单规划

* **怎么验证自己在变好** - 简历与面试训练反馈

## 目标用户画像

* 在校大学生（大一到大四）

* 即将毕业或刚毕业的应届生

* 对职业方向迷茫、缺乏求职经验的学生

## 技术架构

### 前端

* **框架**: React + TypeScript + Vite

* **UI库**: Ant Design (适合中文场景、组件丰富)

* **状态管理**: Zustand (轻量级)

* **路由**: React Router v6

### 后端

* **框架**: Python FastAPI (高性能异步、易于集成爬虫和AI)

* **数据存储**: SQLite (轻量级，适合演示) / JSON文件

* **爬虫**: requests + BeautifulSoup4 (简单实用)

* **AI集成**: OpenAI API / 国内可用的大模型API

### 部署

* 前端打包为静态文件

* 后端提供API服务

* 本地可运行，便于演示

## 功能模块

### 模块1: 职位爬虫与数据采集

**功能**:

* 爬取主流招聘网站（如Boss直聘、拉勾网、前程无忧等）的职位信息

* 提取关键字段：岗位名称、薪资、地点、经验要求、技能要求、工作内容

* 数据存储与去重

**技术要点**:

* 反爬策略处理（User-Agent轮换、请求间隔）

* 数据清洗与标准化

* 支持按关键词搜索（如"前端开发"、"数据分析"）

### 模块2: 岗位智能解析

**功能**:

* 将晦涩的招聘JD翻译为"真实工作内容+能力要求"

* 技能分类：硬技能（编程语言、工具）vs 软技能（沟通、团队协作）

* 技能难度分级：入门/进阶/精通

* 可视化展示技能雷达图

**技术要点**:

* AI大模型分析JD文本

* 结构化输出（JSON格式）

* 前端图表展示（ECharts）

### 模块3: 能力差距分析

**功能**:

* 用户输入自身技能水平

* 对比目标岗位要求，计算匹配度

* 生成差距分析报告

* 推荐需要优先补足的能力

**技术要点**:

* 技能匹配算法

* 权重计算（核心技能 vs 加分技能）

* 可视化对比展示

### 模块4: 阶段性行动清单

**功能**:

* 根据目标岗位生成个性化学习路径

* 分阶段规划：

  * **阶段1**: 基础知识补充（课程/书籍推荐）

  * **阶段2**: 实践项目建议（适合写进简历的项目）

  * **阶段3**: 作品集准备（GitHub/个人博客）

  * **阶段4**: 面试冲刺（高频面试题+模拟）

* 可勾选完成的清单式UI

**技术要点**:

* AI生成个性化内容

* 本地存储进度

* 时间线/甘特图展示

### 模块5: 简历优化助手

**功能**:

* 简历模板选择（技术岗/产品岗/运营岗等）

* AI简历评分与修改建议

* STAR法则指导（情境-任务-行动-结果）

* 关键词优化（匹配目标JD）

**技术要点**:

* AI文本分析与生成

* 模板渲染

* 实时反馈

### 模块6: 模拟面试与反馈

**功能**:

* AI模拟面试官（文字对话形式）

* 分类型面试：技术面/HR面/行为面

* 实时回答评估与建议

* 面试表现报告（优势/待改进点）

**技术要点**:

* 对话式AI交互

* 语音输入输出（可选，进阶功能）

* 评分系统

### 模块7: 岗位探索与推荐

**功能**:

* 根据用户专业/兴趣推荐岗位方向

* 岗位发展路径可视化（初级→中级→高级→专家）

* 行业趋势分析

* 薪资水平参考

**技术要点**:

* 数据分析与可视化

* 推荐算法

## 关键技术决策

### AI API选择

* **首选**: 国内可用的大模型API（如通义千问、智谱AI、文心一言等）

* **备选**: OpenAI API（需科学上网）

* **降级方案**: 使用本地规则引擎（无AI时仍可运行基础功能）

### 爬虫策略

* 优先使用公开API或RSS

* 模拟浏览器请求

* 添加请求间隔，避免对目标网站造成压力

### 数据持久化

* 开发阶段: JSON文件存储（简单易用）

* 如需扩展: 可迁移至SQLite

## 成功指标

* 能够展示真实的岗位数据分析

* 行动清单具有可操作性

* 用户可以清晰看到自己的成长路径

## 风险与应对

| 风险        | 影响     | 应对策略             |
| --------- | ------ | ---------------- |
| 爬虫被封      | 无法获取数据 | 准备演示用静态数据、多源爬虫   |
| AI API不可用 | 核心功能受限 | 降级到规则引擎、准备备选API  |
| 开发时间不足    | 功能不完整  | 优先保证核心功能，次要功能可简化 |
| 数据质量差     | 分析结果不准 | 数据清洗、人工标注样本      |

## 差异化亮点

1. **真实数据驱动** - 不是空泛建议，而是基于真实招聘需求
2. **AI深度解析** - 把JD"翻译"成学生能理解的语言
3. **闭环设计** - 从了解岗位到准备面试的完整链路
4. **进度可视化** - 清楚看到自己在变好
5. **大学生视角** - 开发者也是大学生，更懂用户痛点
